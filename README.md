# XAUUSD & MT5 3D Trading Floor — Quỹ Giao Dịch Vàng Đa Tác Nhân

Ứng dụng sàn giao dịch 3D WebGL đa tác nhân (10 AI Agents, 4 Phòng ban chuẩn Prop Desk) xây dựng bằng React, TypeScript, Tailwind CSS, `@react-three/fiber`, `@react-three/drei` và `lucide-react`.

## Chạy dự án trên máy tính cá nhân

Yêu cầu: **Node.js 18+** (khuyên dùng Node 20/24 LTS).

```bash
# 1. Cài đặt thư viện
npm install

# 2. Chạy môi trường phát triển (Dev Server)
npm run dev

# 3. Đóng gói bản Production
npm run build
```

Sau khi chạy `npm run dev`, mở trình duyệt tại `http://localhost:5173`.
